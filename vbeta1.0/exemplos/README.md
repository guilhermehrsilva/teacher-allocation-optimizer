# Bases de demonstração

`BASE_DEMONSTRACAO_ANONIMIZADA_M52.xlsx` é uma cópia da base sintética de
homologação com nomes, chapas, gestores, coordenadores, comentários, links e
metadados pessoais substituídos. Ela existe exclusivamente para demonstração
interna do fluxo do módulo 52.

O release não inclui resultados anteriores nem banco preenchido. A apresentação
começa com o upload dessa base e permite acompanhar todas as etapas reais.

Para regenerar a planilha a partir de uma fonte sintética aprovada, use
`scripts/anonimizar_base_demo.py`. Nunca aplique esse utilitário como substituto
de uma avaliação formal de privacidade sobre bases reais.

O roteiro recomendado está em `docs/08_QUALIDADE_E_HOMOLOGACAO.md`.
